# BarberQ

Aplikasi antrean dan pemesanan layanan barber, dengan layanan backend dan antarmuka web terpisah.

## Kegunaan

- Pemesanan jadwal layanan barber.
- Pengelolaan antrean harian.
- Pencatatan layanan dan riwayat pelanggan.

## Tech stack

| Lapis | Teknologi |
|---|---|
| Struktur | Backend dan frontend dipisah, masing-masing satu folder |
| Infrastruktur | Dijalankan sebagai dua layanan |
| Detail | Stack rinci tidak dipublikasikan |

## Alur singkat

1. Pelanggan memilih layanan dan waktu.
2. Pesanan masuk ke antrean barber.
3. Status layanan diperbarui sampai selesai.
